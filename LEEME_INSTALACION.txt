THE UNKNOWN FILES

INICIO EN WINDOWS
Abre PowerShell en la carpeta que contiene app.py.

1. python -m venv .venv
2. .\.venv\Scripts\python.exe -m pip install -r requirements.txt
3. $env:MONGO_URI = 'PEGA_AQUI_TU_CADENA_DE_ATLAS'
4. .\.venv\Scripts\python.exe app.py
5. Abre http://127.0.0.1:5000

Sustituye el texto del paso 3 por tu conexión real de Atlas.
Si omites MONGO_URI en local, la aplicación usa MongoDB en 127.0.0.1:27017.
Las variables del proceso configuran la aplicación.

PUBLICACIÓN EN RENDER
Instalación: pip install -r requirements.txt
Inicio: gunicorn app:app --bind 0.0.0.0:$PORT
Configura MONGO_URI en Environment y autoriza en Atlas las IP de salida.
La base es the_unknown_files. Usa casos, escenas, partidas y saldos.

COMPROBAR EL QR
Abre el Taller desde Render, registra un caso y usa Mostrar código QR.
Escanea con el celular, edita el caso y vuelve a escanear el mismo QR.
APP_BASE_URL permite configurar manualmente el dominio público.

PRUEBA DE API
Con Flask iniciado:
.\.venv\Scripts\python.exe probar_api.py

Para la versión publicada:
.\.venv\Scripts\python.exe probar_api.py https://the-unknown-files.onrender.com

La prueba crea y elimina su propio registro de demostración.

PARTIDAS Y PUNTOS
El progreso y saldo se asocian al navegador mediante uf_player.
El carrito permite comprar puntos de forma simulada y gratuita.
La reserva temporal y el uso de puntos para adquirir contenido están
pendientes de definir con el equipo.

Consulta README.md para las funciones actuales y pendientes de entrega.
